WINDOWS 本地工具

智慧树学习助手

下载后解压，在 Edge 已登录智慧树的电脑上运行。下面的内容只有使用方法和 API Key 配置。

下载 ZIP（约 12 KB）

使用方法

  1. 下载 ZIP，解压到任意文件夹，不要在压缩包里直接运行。
  2. 用 Microsoft Edge 打开智慧树课程页面并登录，确认能看到视频和左侧章节目录。
  3. 双击解压目录里的 Start-Helper.cmd。
  4. 程序会打印当前章节并自动播放。保持智慧树标签页打开，Edge 可以最小化。
  5. 需要停止时，在程序窗口按 Ctrl+C。

章节测试只会跳过，不会进入、选择或提交；平台如果强制要求先完成测试才解锁下一章，需要手动完成测试。

配置 API Key

用记事本打开解压目录里的 config.json，把 apiKey 改成你的 Key。保存后重新启动程序。 

{
  "autoAnswer": true,
  "autoNext": true,
  "skipChapterTests": true,
  "pollSeconds": 2,
  "apiBase": "https://api.deepseek.com",
  "model": "deepseek-chat",
  "apiKey": "你的Key"
}

如果使用其他 OpenAI 兼容接口，把 apiBase 和 model 改成对应值即可。 不填写 Key 也能运行，遇到随堂练习时程序会在控制台让你输入 A、B 或 A,C。

API Key 只保存在本机的 config.json，不会上传到本站。
