为什么不是纯网页版？

浏览器安全策略不允许一个网页读取或控制另一个标签页里的智慧树页面，也不能模拟 Windows 桌面点击。 所以自动播放、随堂练习和续节必须作为本机程序运行；这个页面负责下载、说明和版本更新。

LOCAL FIRST
WHAT IT DOES

把重复操作收进后台.

它不是刷课平台的替代品，只是一个减少重复点击的本地小工具。

自动播放

识别当前视频，点击播放；暂停后自动恢复，视频结束自动进入下一节。

随堂练习

检测题目和选项。配置 API Key 可自动作答；不配置则在控制台手动选择。

跳过章节测试

遇到测试直接跳过，不进入、不选择、不提交，尝试下一章内容。

卡住重试

视频结束后如果没有成功切换，会等待、确认并重试，不再一直停在“已播放完”。

标签页恢复

Edge 最小化或切换到其他标签页后，会自动恢复窗口并切回智慧树。

本地日志

每次运行、每次跳转、每次答题都写入本地日志，出问题可以直接定位。

GET STARTED

四步开始.

不需要安装 Node、Python 或任何运行库，Windows 自带的 PowerShell 就够。

01

下载并解压

下载 ZIP，解压到任意文件夹。不要在压缩包内直接双击运行。

02

登录课程

用 Microsoft Edge 打开智慧树课程页并登录，确认能看到视频和左侧目录。

03

双击启动

双击 Start-Helper.cmd。程序会打印当前章节和视频状态。

04

保持页面打开

Edge 可以最小化，但不要关闭智慧树标签页。需要停止时按 Ctrl+C。

FAQ

先把疑问放这里.

如果还有问题，可以点右上角“联系我”。

没有 API Key 能用吗？

可以。遇到随堂练习时，程序会在控制台显示题目和选项，你输入 A、B 或 A,C 即可。配置 Key 后才会自动作答。

它会帮我做章节测试吗？

不会。程序只跳过章节测试，不进入、不点选项、不提交。考试、人脸识别和监考环节也不会处理。

为什么视频结束以后会停住？

有些小节只是目录页，没有视频；也可能是页面切换较慢。程序现在会等待 7 秒，之后跳过测试并向后尝试最多 6 个小节，连续 3 次失败才会停止。

平台要求先通过测试才能看下一章怎么办？

这是平台的服务端顺序限制，程序无法绕过。需要手动完成该章节测试后，再启动程序继续。

Windows 提示脚本有风险？

这是未签名的本地 PowerShell 脚本，Windows 可能弹出提示。确认文件来自本页后，右键查看属性并解除锁定，或在提示中选择“仍要运行”。

为什么不能直接在这个网页里运行？

浏览器不允许网页读取另一个标签页的内容，也不允许模拟桌面点击。自动播放和答题需要 Edge 的 UI Automation，只能在本机运行。
